# Third-party notices
The GAC Card Scanner pilot uses the open-source components below. Each one keeps its own license; full license texts ship inside each installed package (`.venv/lib/python3*/site-packages/<pkg>-*.dist-info/`) or at the linked project. **One Python dependency is GPL: gender-guesser (GPL-3.0)**, listed below. GAC accepted this for the internal pilot tool. Note that the pilot zip/install therefore includes GPL-licensed code when its requirements are installed; if the scanner is ever redistributed outside GAC, GPL-3.0 terms apply to that component (or replace it with a permissively licensed name list). GPL/AGPL components are flagged whenever they are added (see OSS-SURVEY.md; for example paperless-ngx GPL-3.0 and MinerU AGPL-derived were reviewed for ideas only, and no code was copied).
